# 海外企业后缀缩写对照表

> 按地区归类，都是公司法律形式后缀，常用于英文公司名末尾

## 🇸🇬 新加坡 / 东南亚

Pte. Ltd. — Private Limited，私人有限公司（新加坡标准，不能公开募股）
Sdn Bhd — Sendirian Berhad，私人有限公司（马来西亚）
Sdn = Sendirian（私人）；Bhd = Berhad（有限）
Bhd — Berhad，公众有限公司（马来西亚，可上市）

## 🇺🇸 美国

LLC — Limited Liability Company，有限责任企业（穿透税制，无股票）
Inc. — Incorporated，股份有限公司（最常见美式公司）
Corp. — Corporation，公司 / 法人团体，和 Inc 基本通用
LP — Limited Partnership，有限合伙（有普通合伙人 + 有限合伙人）
LLP — Limited Liability Partnership，有限责任合伙（律所 / 会计师事务所常用）
PC — Professional Corporation，专业人士公司（医生、律师）

## 🇬🇧 英国 / 欧盟

Ltd — Limited，有限责任公司（英国私司）
PLC — Public Limited Company，公众有限公司（可上市，英 / 爱尔兰）
GmbH — Gesellschaft mit beschränkter Haftung，有限责任公司（德国、奥地利）
AG — Aktiengesellschaft，股份公司（德 / 瑞士，可上市）
BV — Besloten Vennootschap，私人有限责任公司（荷兰）
NV — Naamloze Vennootschap，股份公司（荷兰 / 比利时，可上市）

## 🇯🇵 日本

K.K./ 株式会社 — Kabushiki Kaisha，株式会社（股份公司）
G.K. — Gōdō Kaisha，合同会社（类似美国 LLC）

## 🇨🇳 中国企业英译

Co., Ltd. — Company Limited，有限责任公司（国内标准英译）
Corp., Ltd. 也常用，但不是法定英文

## 🇦🇺 澳大利亚 / 新西兰

Pty Ltd — Proprietary Limited，私人有限公司（澳新）
Pty = Proprietary，等同于新加坡 Pte
Ltd：Public Limited 公众公司

## 🇨🇦 加拿大

Inc. / Ltd. / Corp. 都广泛使用
ULC — Unlimited Liability Company，无限责任公司（BC 省特有）

## 极简速记区分

Pte / Pty / Sdn：私人（非上市，股份不能公开卖）
LLC / G.K.：有限责任、非传统股份公司，税务特殊
Inc / Corp / K.K / AG / NV / Bhd / PLC：股份制法人，部分可上市

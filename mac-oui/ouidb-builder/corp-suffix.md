# 海外企业后缀缩写对照表

> 按地区归类，都是公司法律形式后缀，常用于英文公司名末尾
> 所有后缀在 ouidb-builder 中已实现大小写不敏感匹配（含点号变体）

## 新加坡 / 东南亚

Pte. Ltd. — Private Limited，私人有限公司（新加坡标准，不能公开募股）
Sdn Bhd — Sendirian Berhad，私人有限公司（马来西亚）
Bhd — Berhad，公众有限公司（马来西亚，可上市）

## 极简速记区分

- Pte / Pty / Sdn / Pvt：私人（非上市，股份不能公开卖）
- LLC / G.K. / Kft. / Sp. z o.o. / d.o.o. / s.r.o. / ehf. / e.U.：有限责任、非传统股份公司
- Inc / Corp / K.K / AG / NV / Bhd / PLC / S.p.A. / Zrt. / A/S / A.Ş. / d.d. / A.D.：股份制法人，部分可上市
- KG / e.K. / Sp. k. / s.c. / sp.j. / HB / Bt. / Kkt.：合伙制 / 个体经营形式
